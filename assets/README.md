# Mission reference maps

The game displays these supplied images in the Level 3 and Level 4 collection galleries.

| Asset | In-game use |
|---|---|
| `mission-photos/elevation.png` | Compare surface colors with an elevation scale. |
| `mission-photos/terrain.png` | Inspect craters, ridges, and rough ground. |
| `mission-photos/surface-map.png` | Compare features across a regional map. |

Original source URLs, creators, and reuse terms are pending verification. These maps are distinct from the NASA Images records requested at runtime. See [credits](../CREDITS.md) for those records and the project license.
